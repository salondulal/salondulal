- Implemented user authentication and role-based access.

### 02 — Environmental Scene Classification

**Python | TensorFlow | Keras | Computer Vision**

A computer vision project exploring image classification across six environmental categories: buildings, forest, glacier, mountain, sea and street.

- Developed and evaluated a baseline classification model.
- Improved model architecture and training performance.
- Investigated model robustness using noisy image inputs.

**Measured results:**

| Evaluation     | Baseline | Improved |
| -------------- | -------: | -------: |
| Clean accuracy |   67.38% |   90.71% |
| Noisy accuracy |   51.90% |   63.81% |

**Focus:** Machine learning, model evaluation, experimentation and robustness.
